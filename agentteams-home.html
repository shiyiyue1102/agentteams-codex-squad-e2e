从目标到交付

分工交给 Agent，
方向始终由你掌握。

把零散的 Agent 会话，组织成有角色、有上下文、有人类参与的协作过程。

01 / 定义目标

把要做的事说清楚

在 Matrix 房间里提出需求，补充背景与验收标准。你与 Agent 共享同一段任务上下文。

02 / 协作执行

让合适的角色来完成

Manager 协调 Workers，各自使用适合的运行时和工具，通过共享文件交换工作成果。

03 / 共同交付

看见过程，检查结果

进展与反馈回到房间。你可以参与讨论、澄清问题，并在交付前检查最终成果。

AgentTeams Dashboard

一个控制台，
掌握整支团队。

从团队拓扑到任务进展，从房间对话到运行诊断，在同一个工作台管理 Workers、Teams、Humans 与 Managers。

开始使用 Dashboard → 探索 Dashboard 源码 ↗
01 / Overview

看清团队全貌

查看资源状态与团队关系，管理 Worker 的唤醒、休眠与生命周期。

02 / Tasks

Human-in-the-loop

在任务看板追踪执行进展，查看待确认事项，并在需要时参与决策。

03 / Chat

对话与执行在一起

内置 Matrix 聊天，呈现线程、工具调用与工作流消息，让协作过程更易追踪。

04 / Resources & Diagnostics

管理能力，定位问题

管理 Skill 与 MCP 资源，收集调试日志，通过 AI 辅助诊断了解运行状况。
