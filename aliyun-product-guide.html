三种角色，一眼分清

它们并非互相替代，也可以协同使用。

COMPUTE / 计算01

ECS

云服务器

提供可配置的计算实例，像一台云上的服务器，用于部署和运行应用程序。

适用场景

  • 部署网站与 API 服务
  • 搭建应用运行环境
  • 执行后台计算任务

选型提醒：需要管理操作系统、应用与安全配置；它不是开箱即用的托管数据库。

OBJECT / 对象存储02

OSS

对象存储

以对象形式存储和访问文件，适合图片、视频等非结构化数据，不负责运行后端代码。

适用场景

  • 存放图片与视频文件
  • 保存网页静态资源
  • 归档备份文件

选型提醒：文件访问需要合理配置权限；它不能替代关系型数据库的事务与查询能力。

DATABASE / 数据库03

RDS

云数据库

提供托管关系型数据库服务，围绕表、关系、查询与事务，管理结构化业务数据。

适用场景

  • 保存订单与用户信息
  • 处理业务交易与事务
  • 进行关系型数据查询

选型提醒：仍需设计表结构、访问权限与备份策略；不用于存放任意文件，也不适合所有数据模型。
